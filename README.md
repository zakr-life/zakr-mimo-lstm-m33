# zakr-mimo-lstm-m33

ZAKR MIMO LSTM Cortex-M33 Reference Implementation

This repository provides a reference implementation of the ZAKR embedded MIMO LSTM inference pipeline optimized for ARM Cortex-M33 microcontrollers.

Features:
- INT8 quantized LSTM inference
- TensorFlow Lite Micro integration
- CMSIS-DSP acceleration
- Real-time PAC feature extraction
- Deterministic latency under 8 ms
- nRF5340 compatible
- Safety-critical bounded execution

Target Hardware:
- Nordic nRF5340
- ARM Cortex-M33 @ 64 MHz
- 512 KB RAM minimum
- DSP extension enabled
